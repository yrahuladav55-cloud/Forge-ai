Connect using any HTTP client or OpenAI SDK compatible library. Simply point your base URL to http://localhost:5000/v1.

cURL • Chat Completions Streaming 
curl -X POST http://localhost:5000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer bf_live_YOUR_API_KEY" \
  -d '{
    "model": "codepulse",
    "messages": [
      {"role": "user", "content": "Create a JavaScript calculator"}
    ],
    "stream": true
  }'
